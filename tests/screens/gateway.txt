### gw.lan.router — ❓ Роутер: вкладка MikroTik
> press gw:lan_router:
= edit #1
❓ <b>Роутер для pi</b> · <code>192.168.1.0/24</code> · шлюз <code>192.168.1.10</code>
Весь трафик сети, кроме шлюза и локального, — на шлюз; DNS по DHCP — шлюз; ускорение и IPv6 — выключить; асимметричный путь — разрешить
<blockquote expandable>• весь трафик локальной сети, кроме самого шлюза и трафика внутри сети, — на адрес шлюза (policy-based routing);
• разрешён асимметричный путь: ответ от шлюза к устройству идёт мимо роутера — правило выше drop invalid;
• аппаратное ускорение (fasttrack, flow offloading) выключено;
• DHCP раздаёт DNS = адрес шлюза; у шлюза статический адрес;
• IPv6 в локальной сети выключен (RA/DHCPv6): резолвер шлюза AAAA не отдаёт, но адрес v6 от роутера увёл бы трафик мимо туннеля</blockquote>
<b>MikroTik RouterOS 7</b>
<pre>/routing table add disabled=no fib name=antiblock
/ip firewall mangle
add action=accept chain=prerouting comment=anti-loop src-address=192.168.1.10
add action=mark-routing chain=prerouting comment=all-LAN-via-gw \
    new-routing-mark=antiblock passthrough=no src-address=192.168.1.0/24 dst-address=!192.168.1.0/24
/ip route add dst-address=0.0.0.0/0 gateway=192.168.1.10 routing-table=antiblock
/ip firewall filter
add action=accept chain=forward comment=asym-via-gw src-address=192.168.1.0/24 dst-address=!192.168.1.0/24
/ip route add dst-address=192.168.2.0/24 gateway=192.168.1.10
/ip dhcp-server network set [find] dns-server=192.168.1.10</pre>
Правило asym-via-gw — выше drop invalid; fasttrack выключить
Связь подсетей: сам роутер отвечает со своего адреса по основной таблице, мимо заворота, — чтобы он был достижим из подсетей других шлюзов, ему нужен маршрут до них через шлюз (строки с <code>192.168.2.0/24</code>). Устройствам за роутером это не нужно
