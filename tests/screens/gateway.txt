### gw.lan.router — 🛜 Роутер: вкладка MikroTik
> press gw:lan_router:
= edit #1
🛜 <b>Настройка роутера для pi</b> · <code>192.168.1.0/24</code> · шлюз <code>192.168.1.10</code>
Весь трафик сети, кроме самого шлюза и трафика внутри сети, — на шлюз; DNS по DHCP — адрес шлюза; ускорение и IPv6 — выключить; асимметричный путь — разрешить
<blockquote expandable>весь трафик локальной сети, кроме самого шлюза и трафика внутри сети, — на адрес шлюза (policy-based routing);
разрешён асимметричный путь: ответ от шлюза к устройству идёт мимо роутера — правило выше <code>drop invalid</code>;
аппаратное ускорение (fasttrack, flow offloading) выключено;
DHCP раздаёт адрес шлюза как DNS; у шлюза статический адрес;
IPv6 в локальной сети выключен (RA/DHCPv6): резолвер шлюза AAAA не отдаёт, но IPv6-адрес от роутера увёл бы трафик мимо туннеля</blockquote>
<b>MikroTik RouterOS 7</b>
<pre>/routing table add disabled=no fib name=antiblock
/ip firewall mangle
add action=accept chain=prerouting comment=anti-loop src-address=192.168.1.10
add action=mark-routing chain=prerouting comment=all-LAN-via-gw \
    new-routing-mark=antiblock passthrough=no src-address=192.168.1.0/24 dst-address=!192.168.1.0/24
/ip route add dst-address=0.0.0.0/0 gateway=192.168.1.10 routing-table=antiblock
/ip firewall filter
add action=accept chain=forward comment=asym-via-gw src-address=192.168.1.0/24 dst-address=!192.168.1.0/24
/ip dhcp-server network set [find] dns-server=192.168.1.10</pre>
Правило <code>asym-via-gw</code> — выше <code>drop invalid</code>; fasttrack выключить

<blockquote expandable>весь трафик локальной сети, кроме самого шлюза и трафика внутри сети, — на адрес шлюза (policy-based routing);

<b>OpenWrt</b>
<pre>echo '200 vpn' &gt;&gt; /etc/iproute2/rt_tables
ip route add default via 192.168.1.10 table vpn
ip rule add from 192.168.1.10 priority 100 lookup main
ip rule add from 192.168.1.0/24 to 192.168.1.0/24 priority 110 lookup main
ip rule add from 192.168.1.0/24 priority 120 lookup vpn

uci set firewall.@defaults[0].flow_offloading_hw='0'
uci set firewall.@defaults[0].flow_offloading='0'
uci add_list dhcp.lan.dhcp_option='6,192.168.1.10'
uci commit</pre>
Порядок важен: сначала исключается сам шлюз, затем трафик внутри сети, потом всё остальное уходит на шлюз. Чтобы правила пережили перезагрузку: <code>ip rule</code>/<code>ip route</code> — в <code>/etc/rc.local</code>, <code>iptables</code> — в <code>/etc/firewall.user</code>
