### adm.set.dns — свой DNS-резолвер
> press set:dns:open::
= edit #1
🔒 <b>Свой DNS-резолвер</b> сейчас публичный
Свой — <code>10.8.1.1</code>: меньшие задержки, запросы не уходят третьим лицам, защита от обхода через DoH. Цена — переезд профилей при включении<blockquote expandable>Сервер умеет отвечать сам — dnsmasq на собственном адресе в туннеле — и это даёт три вещи:
• РФ-доступ у всех, а не «через раз»: с публичным адресом Chrome и Edge молча уходят на DoH мимо сервера, набор адресов не наполняется, и у такого человека российские сайты ругаются;
• DNS-запросы клиентов не уходят третьей стороне открытым текстом — резолвит сервер, наружу идёт уже от него, с кэшем;
• защита от DoH-обхода и DNS rebinding с первого дня, а не только со шлюзом.
Цена: адрес DNS вшит в каждую выданную ссылку, поэтому переход — это переезд профилей: рядом поднимается новый интерфейс, у каждого устройства рождается двойник, люди переносят конфиги когда удобно, старые пиры работают до финала</blockquote>

### adm.gw.router — рецепт роутера: MikroTik
> press gws:router:1:
= edit #1
❓ <b>Роутер для NASPi</b> · <code>192.168.1.0/24</code> · шлюз <code>АДРЕС_ШЛЮЗА</code>
Весь трафик сети, кроме шлюза и локального, — на шлюз; DNS по DHCP — шлюз; ускорение и IPv6 — выключить; асимметричный путь — разрешить
<blockquote expandable>• весь трафик локальной сети, кроме самого шлюза и трафика внутри сети, — на адрес шлюза (policy-based routing);
• разрешён асимметричный путь: ответ от шлюза к устройству идёт мимо роутера — правило выше drop invalid;
• аппаратное ускорение (fasttrack, flow offloading) выключено;
• DHCP раздаёт DNS = адрес шлюза; у шлюза статический адрес;
• IPv6 в локальной сети выключен (RA/DHCPv6): резолвер шлюза AAAA не отдаёт, но адрес v6 от роутера увёл бы трафик мимо туннеля</blockquote>
<b>MikroTik RouterOS 7</b>
<pre>/routing table add disabled=no fib name=antiblock
/ip firewall mangle
add action=accept chain=prerouting comment=anti-loop src-address=АДРЕС_ШЛЮЗА
add action=mark-routing chain=prerouting comment=all-LAN-via-gw \
    new-routing-mark=antiblock passthrough=no src-address=192.168.1.0/24 dst-address=!192.168.1.0/24
/ip route add dst-address=0.0.0.0/0 gateway=АДРЕС_ШЛЮЗА routing-table=antiblock
/ip firewall filter
add action=accept chain=forward comment=asym-via-gw src-address=192.168.1.0/24 dst-address=!192.168.1.0/24
/ip dhcp-server network set [find] dns-server=АДРЕС_ШЛЮЗА</pre>
Правило asym-via-gw — выше drop invalid; fasttrack выключить

<pre>echo '200 vpn' &gt;&gt; /etc/iproute2/rt_tables
ip route add default via АДРЕС_ШЛЮЗА table vpn
ip rule add from АДРЕС_ШЛЮЗА priority 100 lookup main

uci set firewall.@defaults[0].flow_offloading_hw='0'
uci set firewall.@defaults[0].flow_offloading='0'
uci add_list dhcp.lan.dhcp_option='6,АДРЕС_ШЛЮЗА'
uci commit</pre>
