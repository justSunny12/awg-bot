# Роль «гость» и переданные устройства — концепт v2.20.0

Согласовано 16.09.2026. Заменяет прежнюю модель «друг = tg_id на устройстве».

## Модель

**Два типа профилей.** `владелец` (`clients.kind = owner`) — как раньше: подписка,
лимит устройств, квота. `гость` (`kind = guest`) — профиль без своей подписки:
заводится автоматически при первой активации кода `F…`, имя — из
Telegram-аккаунта, живёт, пока держит хоть одно устройство.

**У устройства две стороны.** *Владелец* (`devices.client_id` — слот, квота,
подписка, разрешение РФ-доступа) и *держатель* (`devices.holder_client_id` —
кто управляет через бота; NULL — сам владелец). Переданное устройство:
владелец — даритель, держатель — гость **или обычный клиент**. Слот и квоту
оно ест у дарителя, у держателя не занимает.

**Один даритель.** Любой держатель держит чужие устройства только от одного
владельца. Код от другого отбивается, код не сгорает.

**Субъект РФ-доступа — держатель.** Его тумблеры, список адресов, наборы — для
всех устройств, которые он держит. *Разрешение* наследуется от владельца
устройства: снял админ фичу у дарителя — переданные устройства выпадают из
режима у держателя; вернул — вернулось, списки и тумблеры хранятся.

**Гость → владелец.** Гость активирует клиентский инвайт: профиль меняет тип
и получает подписку, **все** переданные ему устройства становятся его
собственными независимо от лимита («3 из 2» честно), слоты дарителю
возвращаются, управлять ими он больше не может. Новое устройство — когда
появится свободный слот. Пиры не трогаются. Помощь с настройкой не
предлагаем — сразу главное меню.

**Переход данных.** Прежние «друзья» (`device_friend.friend_tg_id`, status
active) при обновлении становятся гостевыми профилями; имя подтягивается из
Telegram при первом сообщении (до этого — «Друг»). `device_friend` остаётся
только для ожидающих кодов (`pending`).

## Экраны

**Гость — главный.** Как клиентский: «Привет, {имя из Telegram}! 👋»,
статус сервера, строка РФ-доступа (только при фиче у владельца), «Статус
подписки: 🟢 активна (владелец: [Вася](tg://user?id=…))», «У тебя N
устройств». Кнопки: 📱 Мои устройства (всегда) · 🇷🇺 Доступ к РФ-сервисам (при
фиче) · 🔗 Ссылка · 🔳 QR-код · 📄 Файл · ❓ Помощь с настройкой.

**Обычный клиент с чужими устройствами.** Строка устройств: «У тебя 2 из 3
устройств + 1 от [Вася]». В «Мои устройства» чужие — после своих, с
пометкой; «Добавить устройство» считает только свои.

**Карточка у держателя.** Статистика + «Потребление за месяц: … — лимит
устройства N ГБ / лимит профиля владельца N ГБ / без ограничения» + «👤
Получено от [Вася]». Кнопки: 🔌 Данные для подключения · 🛑 Заблокировать /
▶️ Разблокировать · 🗑 Удалить · ⬅️ Назад. Имя держатель не меняет.

**Карточка переданного у владельца.** Та же статистика, «👤 Передано [Артём]
и управляется им». Кнопки: ✏️ Имя · 🗑 Удалить · ⬅️ Назад.

**Раздел РФ-доступа у владельца.** Переданные — в конце списка строкой
«Ноутбук — [Артём]» без переключателя, в «Устройства: N из M» не считаются;
последняя строка инфобокса: «Друзья, которым ты передал устройства, управляют
функцией самостоятельно.»

## Диалоги и тексты

**Блокировка — с подтверждением** (клиент и гость; у админа шаг подтверждения
— выбор «тихо / с уведомлением»): «Заблокировать «тест3»? Устройство перестанет
подключаться, пока ты его не разблокируешь.» — ⬅️ Отмена / 🛑 Заблокировать.

**Удаление переданного держателем:** «Удалить «тест3»? Это устройство,
переданное другом: после удаления доступ с него пропадёт, а создать новое ты
не сможешь — только получить новый код от друга.» Владельцу: «Устройство
«тест3», ранее переданное [Артём], удалено по его запросу.\nТеперь у тебя 1
из 3 устройств.» Держателю — «🗑 Устройство «тест3» удалено.» и главный экран;
гость без устройств: «Устройств больше нет. Чтобы снова пользоваться VPN,
попроси у друга новый код.» — профиль гостя закрывается.

**Удаление переданного владельцем:** «Удалить «тест3»? Устройство передано
[Артём]: у него пропадёт доступ с этого устройства, а создать новое сам он не
сможет — только получить от тебя новый код.» Держателю: «Устройство «тест3»,
которым ты управлял, удалено владельцем ([Вася]) — доступ по нему больше не
работает.»

**Ещё одно устройство от того же владельца** (`/start F…` / `/code F…`):
«✅ Устройство «Ноутбук» от [Вася] успешно добавлено.\nТеперь у тебя 2
устройства.» (вторая строка — если больше одного; у клиента — «Теперь у тебя
2 из 3 устройств + 1 от [Вася]») → главный экран. Владельцу — «👤 Друг
(@handle) активировал устройство «…»».

**Код от другого владельца:** «У тебя уже есть устройства «тест3» и
«Ноутбук», переданные [Вася].\nВладеть устройствами от разных друзей
одновременно не получится 😔\nТы можешь либо удалить все устройства от [Вася]
и отправить мне этот код повторно, либо оставить всё как есть — решать тебе
🤷‍♂️» (одно устройство — единственное число; перечисление через запятую,
перед последним «и»). Код не сгорает.

**Гость активирует клиентский инвайт.** Новому владельцу: «Готово! Доступ
активирован. 🎉\n\nПереданные тебе устройства от профиля [Вася] перенесены в
твой профиль — перенастраивать ничего не нужно, они работают как раньше:\n•
Телефон\n• Ноутбук\n• Планшет»; если больше лимита — «В твою подписку входит
2 устройства, а перенесено 3 — все они продолжают работать. Добавить новое
получится, когда освободится место в рамках лимита.» Прежнему владельцу —
одним сообщением: «📤 Устройства «Ноутбук», «Планшет» и «Телефон» перешли к
[Артём] — он активировал собственную подписку, и устройства переехали в его
профиль. У тебя теперь 1 из 3 устройств.» Админу — к «✅ Активация: …»:
«Перенесено переданных устройств: 3 (от Вася), лимит подписки 2.»

**РФ-доступ — держателю при выдаче/отзыве фичи владельцу:** «К устройствам,
которые тебе передал [Вася], добавлена функция РФ-доступа 🎉\nС ней можно
пользоваться РФ-приложениями и сайтами, не выключая VPN.\nФункция
автоматически включена для всех твоих устройств — выключить (ну мало ли
вдруг) можешь сам через меню бота.\n\nЕсли какой-то сайт продолжает ругаться
на включённый VPN — добавь его в список обхода через пункт меню бота «Доступ
к РФ-сервисам».» / «Функция РФ-доступа для устройств от [Вася] больше
недоступна 😔\nДля доступа к РФ-сайтам и приложениям, ругающимся на VPN,
теперь придётся его выключать.»

**Финишеры создания:** «✅ Устройство «ыва» создано.\nПотребление устройства
не ограничено в рамках лимита профиля.\nКоличество устройств: 2/3» / «…создано
для друга.\nПотребление устройства не ограничено в рамках твоего лимита
профиля.\nКоличество устройств: 2/3». С лимитом — «Потребление устройства:
20 ГБ.»; профиль без лимита потребления — «Потребление устройства не
ограничено.»; без лимита устройств — «Количество устройств: 2».

## Порядок работ

(1) модель — тип профиля, держатель, перенос прежних друзей, роль гостя в
middleware; (2) экраны гостя и карточки переданных у обеих сторон,
подтверждения, финишеры; (3) коды: второй от того же, отказ на чужого,
апгрейд во владельца; (4) РФ-доступ по держателю + уведомления. Релиз один,
v2.20.0, только основной бот.
